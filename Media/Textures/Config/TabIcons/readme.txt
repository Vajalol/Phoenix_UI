Phoenix UI Tab Icons

This directory contains icons used for the configuration tab system in Phoenix UI.
Icons are 32x32 pixels with transparent backgrounds.

Icon naming convention:
- icon_general.tga - General settings
- icon_frames.tga - Unit frames settings
- icon_auras.tga - Buffs and debuffs settings
- icon_castbar.tga - Castbar settings
- icon_nameplates.tga - Nameplate settings
- icon_combat.tga - Combat text settings
- icon_raids.tga - Raid frames settings
- icon_stats.tga - Player stats settings
- icon_minimap.tga - Minimap settings
- icon_bars.tga - Action bars settings
- icon_themes.tga - Themes and styling settings

Icons should follow the Phoenix UI Flame Theme visual style.
